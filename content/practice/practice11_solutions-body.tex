\[\varepsilon_{QR}=\frac{\partial Q}{\partial R}\cdot\frac{R}{Q}=\frac{1}{2}R^{-1/2}\cdot\frac{R}{Q}=\frac{R^{1/2}}{2\left(a+bP^{2}+R^{1/2}\right)}\]

\item[5.] Write $Q=a+bP^{2}+R^{1/2}$ and assume $Q>0$. For $\varepsilon_{QP}=2bP^{2}/Q$:
\[\frac{\partial \varepsilon_{QP}}{\partial P}=\frac{4bP\,Q-2bP^{2}\cdot 2bP}{Q^{2}}=\frac{4bP\left(a+R^{1/2}\right)}{Q^{2}}\]
\[\frac{\partial \varepsilon_{QP}}{\partial R}=\frac{-bP^{2}R^{-1/2}}{Q^{2}}<0\]
So $\varepsilon_{QP}$ is strictly decreasing in $R$. In $P$ it is strictly increasing if $a+R^{1/2}>0$ and strictly decreasing if $a+R^{1/2}<0$: the sign does not depend on $P$, so it is strictly monotonic in $P$ either way.

For $\varepsilon_{QR}=R^{1/2}/(2Q)$:
\[\frac{\partial \varepsilon_{QR}}{\partial P}=\frac{-bP\,R^{1/2}}{Q^{2}}<0\]
\[\frac{\partial \varepsilon_{QR}}{\partial R}=\frac{R^{-1/2}\,Q-1}{4Q^{2}}=\frac{R^{-1/2}\left(a+bP^{2}\right)}{4Q^{2}}\]
So $\varepsilon_{QR}$ is strictly decreasing in $P$. In $R$ it is strictly increasing if $a+bP^{2}>0$ and strictly decreasing if $a+bP^{2}<0$: again the sign does not depend on $R$, so it is strictly monotonic in $R$.
