\underline{Exercise 11.2}
\begin{enumerate}
% Question 1
\item[1.] $z = x^{2} + xy + 2y^{2} + 3$

The first-order conditions are
\[z_x = 2x + y = 0 \quad\text{and}\quad z_y = x + 4y = 0\]
which give $(x^{*}, y^{*}) = (0, 0)$, with $z^{*} = 3$. At this point,
\[z_{xx} = 2 > 0, \quad z_{yy} = 4 > 0, \quad z_{xy} = 1, \quad z_{xx} z_{yy} = 8 > 1 = z_{xy}^{2}\]
so $z^{*}$ is a minimum.

% Question 2
\item[2.] $z = -x^{2} - y^{2} + 6x + 2y$

The first-order conditions are
\[z_x = -2x + 6 = 0 \quad\text{and}\quad z_y = -2y + 2 = 0\]
which give $(x^{*}, y^{*}) = (3, 1)$, with $z^{*} = 10$. At this point,
\[z_{xx} = -2 < 0, \quad z_{yy} = -2 < 0, \quad z_{xy} = 0, \quad z_{xx} z_{yy} = 4 > 0 = z_{xy}^{2}\]
so $z^{*}$ is a maximum.

% Question 3
\item[3.] $z = ax^{2} + by^{2} + c$

The first-order conditions $z_x = 2ax = 0$ and $z_y = 2by = 0$ give $(x^{*}, y^{*}) = (0, 0)$, with $z^{*} = c$. Here $z_{xx} = 2a$, $z_{yy} = 2b$, $z_{xy} = 0$, and $z_{xx} z_{yy} = 4ab$.
\begin{enumerate}
\item[(a)] With $a, b > 0$, $z_{xx} > 0$, $z_{yy} > 0$, and $4ab > 0$, so $z^{*} = c$ is a minimum.
\item[(b)] With $a, b < 0$, $z_{xx} < 0$, $z_{yy} < 0$, and $4ab > 0$, so $z^{*} = c$ is a maximum.
\item[(c)] With $a$ and $b$ opposite in sign, $4ab < 0 = z_{xy}^{2}$, so $(0, 0)$ is a saddle point: neither a maximum nor a minimum.
\end{enumerate}

% Question 4
\item[4.] $z = e^{2x} - 2x + 2y^{2} + 3$

The first-order conditions are
\[z_x = 2e^{2x} - 2 = 0 \quad\text{and}\quad z_y = 4y = 0\]
which give $(x^{*}, y^{*}) = (0, 0)$, with $z^{*} = 4$. At this point,
\[z_{xx} = 4e^{2x} = 4 > 0, \quad z_{yy} = 4 > 0, \quad z_{xy} = 0, \quad z_{xx} z_{yy} = 16 > 0 = z_{xy}^{2}\]
so $z^{*}$ is a minimum.

% Question 5
\item[5.] $z = (x-2)^{4} + (y-3)^{4}$
\begin{enumerate}
\item[(a)] $(x-2)^{4}$ and $(y-3)^{4}$ are never negative, and both are zero only at $x = 2$, $y = 3$. So $z \geq 0$ everywhere, with $z^{*} = 0$ at $(2, 3)$.
\item[(b)] Yes. $z_x = 4(x-2)^{3}$ and $z_y = 4(y-3)^{3}$ are both zero at $(2, 3)$.
\item[(c)] No. $z_{xx} = 12(x-2)^{2}$, $z_{yy} = 12(y-3)^{2}$, and $z_{xy} = 0$ are all zero at $(2, 3)$, so $z_{xx} > 0$ fails. The second-order condition is sufficient, not necessary: this point is a minimum even though the condition does not hold.
\end{enumerate}

\end{enumerate}
