Find $f''(x)$ for each function, and decide whether $f$ is strictly concave, strictly convex, or neither.
\begin{itemize}
  \item[(a)] $f(x) = -x^2 + 4x + 1$
  \vspace{5cm}
  \item[(b)] $f(x) = \ln x$, \quad $x > 0$
  \vspace{5cm}
  \item[(c)] $f(x) = x^4 - 4x^3$. If $f$ is neither, on what interval is it concave?
\end{itemize}

Given the quadratic profit function
\[ \pi(Q) = hQ^2 + jQ + k \]
what parameter restrictions are called for to reflect the following assumptions?
\begin{itemize}
  \item[(a)] If nothing is produced, the profit will be negative (because of fixed costs).
  \vspace{2.5cm}
  \item[(b)] The profit function is strictly concave ($\pi''(Q) < 0$ for all $Q$).
  \vspace{5cm}
  \item[(c)] The maximum profit occurs at a positive output level $Q^*$.
\end{itemize}
