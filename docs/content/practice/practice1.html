Exercise 2.3

1. Write the following in set notation:

  1. The set of all real numbers greater than 34.
  2. The set of all real numbers greater than 8 but less than 65.
Solution
  1. {x∈R∣x>34}, or simply {x∣x>34}
  2. {x∣8<x<65}

2. Given the sets S1={2,4,6}, S2={7,2,6}, S3={4,2,6}, and S4={2,4}, which of the following statements are true?

  1. S1=S3
  2. S1=R
  3. 8∈S2
  4. 3∉S2
  5. 4∉S3
  6. S4⊂R
  7. S1⊃S4
  8. ∅⊂S2
  9. S3⊃{1,2}

Note that R denotes the set of real numbers.

Solution

(a), (d), (f), (g), and (h) are true.
