4. Show that when all the elements of an nth-order determinant |A| are multiplied by a number k, the result will be kn|A|.

Solution

Multiplying every element of an nth-order determinant by k multiplies each of its n rows by k. Multiplying a single row by k multiplies the determinant by k, so doing it to all n rows gives kn|A|.

8. Comment on the validity of the following statements:

  1. Given any matrix A, we can always derive from it a transpose and a determinant.

  2. Multiplying each element of an n×n determinant by 2 will double the value of that determinant.

  3. If a square matrix A vanishes, then we can be sure that the equation system Ax=d is nonsingular.

Solution

  1. False. While we can find the transpose of any matrix, the determinant is only defined for square matrices.

  2. False. Multiplying each element of an n×n by 2 will increase the determinant by 2n times.

  3. A cannot be 0, but the determinant of A can. In any case, if |A|=0, A is singular.

3. a. Drawing on your answers to Prob. 2, formulate a two-step rule for finding the adjoint of a given 2×2 matrix A: In the first step, indicate what should be done to the two diagonal elements of A in order to get the diagonal elements of adjA; in the second step, indicate what should be done to the two off-diagonal elements of A. (Warning: This rule applies only to 2×2 matrices.)

  1. Add a third step which, in conjunction with the previous two steps, yields the 2×2 inverse matrix A−1.
Solution

  1. Step 1: Exchange the two diagonal elements.
    Step 2: Multiply both the off-diagonal elements by -1.

  2. Step 3: Multiply the resulting matrix from steps 1 and 2 by 1/|A|.

7. Is it possible for a matrix to be its own inverse?

Solution

If a matrix is its own inverse, we would need that A2=I. This is true for the identity matrix. There are other possibilities such as matrix G in exercise 4.
