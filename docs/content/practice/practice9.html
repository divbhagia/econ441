Exercise 7.2

3. Differentiate the following by using the product rule:

  1. (ax−b)(cx2)
Solution

Let f(x)=ax−b and g(x)=cx2, so f′(x)=a and g′(x)=2cx.

ddx[f(x)g(x)]=f′(x)g(x)+f(x)g′(x)=acx2+(ax−b)2cx=acx2+2acx2−2bcx=3acx2−2bcx

  1. (2−3x)(1+x)(x+2)
Solution

Let f(x)=(2−3x)(1+x) and g(x)=x+2, so g′(x)=1. Using the product rule on f(x) itself:

f′(x)=−3(1+x)+(2−3x)(1)=−(6x+1)

Then

ddx[f(x)g(x)]=f′(x)g(x)+f(x)g′(x)=−(6x+1)(x+2)+(2−3x)(1+x)=−6x2−13x−2+2−x−3x2=−9x2−14x=−x(9x+14)

4. Given y=(16x+3)−2, use the chain rule to find dy/dx. Then rewrite the function as y=1/(16x+3)2 and find dy/dx by the quotient rule. Are the answers identical?

Solution

Chain rule, with z=16x+3 and y=z−2:

dydx=dydz⋅dzdx=−2z−3(16)=−32(16x+3)3

Quotient rule, where the derivative of the denominator is 2(16x+3)⋅16=32(16x+3):

dydx=0⋅(16x+3)2−1⋅32(16x+3)(16x+3)4=−32(16x+3)3

The answers are identical.
